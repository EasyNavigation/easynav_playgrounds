# Tree models

Meshes and textures of two Gazebo Fuel models, used by `tools/geo_world.py` to plant the trees of a
generated world (merged into one mesh, see `trees.glb` there). Both are **Creative Commons Zero v1.0**
(public domain), by OpenRobotics:

- `oak/`  - [Oak tree](https://app.gazebosim.org/OpenRobotics/fuel/models/Oak%20tree) (6.5 m high, crown radius 5 m)
- `pine/` - [Pine Tree](https://app.gazebosim.org/OpenRobotics/fuel/models/Pine%20Tree) (5.1 m high, crown radius 1.6 m)

(`shrijitsingh99/Juniper Tree` is a byte-identical copy of the pine mesh, so it is not used twice.)
