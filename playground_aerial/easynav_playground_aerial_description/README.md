# EasyNav Aerial Playground: description

The model of the flying saucer used by the EasyNav playgrounds: a 1 m UFO that moves in x, y, z and yaw, keeping its roll and pitch at zero. It carries:
- a front camera (640 x 480, 15 Hz);
- two 3D lidars, on top and underneath (16 x 360 rays, 60 m, 10 Hz);
- an IMU (50 Hz);
- a GPS (10 Hz).

It depends neither on Gazebo nor on EasyNav: `easynav_playground_aerial_worlds` simulates it, and `easynav_playground_aerial` navigates with it.

## Build

From the ROS 2 workspace root:

```bash
rosdep install --from-paths src --ignore-src -r -y
colcon build --symlink-install --packages-up-to easynav_playground_aerial_description
source install/setup.bash
```

To get the URDF:

```bash
xacro $(ros2 pkg prefix easynav_playground_aerial_description)/share/easynav_playground_aerial_description/urdf/ufo.urdf.xacro
```

## Package layout

| Directory | Contents |
| --- | --- |
| `urdf/` | `ufo.urdf.xacro`: the body, the sensors and the Gazebo plugins |
| `meshes/` | The hull and the dome |
| `tools/` | `make_ufo_meshes.py`, which generates the meshes as surfaces of revolution |
